# Ocean Tap

海の中を泳ぐ魚の群れを眺めながら、指でちょっかいを出すだけの小さなゲームです。
目標も点数もないので、何も考えずに暇つぶししたいときに。iPhone の Safari 向けに作っています。

**公開URL：https://niko12-coder.github.io/ocean-tap/**

## 遊び方

| 操作 | 起きること |
|---|---|
| タップ | 波紋が広がり、魚が驚いて逃げる。近くの泡は弾ける |
| 長押し | エサが落ち、魚が集まって食べる |
| なぞる | 泡が出て、魚が泡をよけて泳ぐ |
| 右上の歯車 | 設定パネルを開く |

何もしなくても、群れは画面の中をゆっくり泳ぎ回ります。

### 設定

魚の数・テーマ（標準・浅瀬・深海・夕方の海・サンゴ礁）・省電力（30fps）をすぐ変えられます。「詳細設定」では、魚の動き・泡や粒子の量・海底の飾りなども調整できます。設定はブラウザに保存されます。

### ホーム画面に追加して全画面で遊ぶ

iPhone の Safari で公開URLを開き、共有ボタン →「ホーム画面に追加」。ホーム画面のアイコンから起動すると全画面になります。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | ゲーム本体（HTML・CSS・JavaScript の1ファイル。外部ライブラリなし） |
| `manifest.webmanifest` | ホーム画面に追加したときの設定 |
| `icon-180.png` / `icon-512.png` | アイコン |
| `tools/make-icons.ps1` | アイコンを作り直すスクリプト（PowerShell） |

## 改造のヒント

- `index.html` は番号つきの見出しコメントで区切ってあります。まず触るとよいのは先頭の `CONFIG`（魚の数・泡の上限・群れの動きなどの値）です。
- テーマは `THEMES` に1つ書き足すと、パネルの選択肢にも出ます。
- パネルの項目は `SCHEMA` の1行が1項目です。反映は `applySetting()` に書きます。
- `CONFIG` や `SCHEMA` の初期値を変えたら `SETTINGS_VERSION` を1つ上げてください（古い保存データが捨てられ、新しい初期値で始まります）。

URLオプション：

| 付け方 | 効果 |
|---|---|
| `?fish=30` | 魚の数を一時的に変える |
| `?fps` | fps・処理時間・魚と泡の数を表示する |
| `?debug` | コンソールから `window.__ocean` で中身を見られる |

## 軽さの工夫

- 描画は Canvas 2D のみ。背景や泡の絵は前もって描いて使い回す
- 泡とエサは上限を決めて使い回す
- 動きが重いときは、描画の細かさ → 光の筋 → 魚の数、の順に自動で軽くする（`AUTO_QUALITY`）

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます。サーバーで開くなら：

```bash
python -m http.server 8000
```
